# BizTrack

An invoicing and inventory app for small shops. Shop owners can track stock, record sales, create PDF invoices, and see how the business is doing. Staff accounts have limited permissions.

## Planned features

- Register and log in as an owner or staff member
- Add, edit, and delete products, and track stock
- Record sales, with stock reducing automatically
- Create and download invoices as PDFs
- Dashboard with daily sales, low-stock alerts, and unpaid invoices
- Role-based permissions

## Tech stack

React, Node.js, Express, TypeScript, MongoDB
